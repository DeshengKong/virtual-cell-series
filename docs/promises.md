# 欠账表

对观众许过的每一个愿：在哪期许的，原话是什么，在哪期还。写脚本前先看这张表；每期定稿时更新。

- 期数以 [`curriculum.md`](curriculum.md) v2 为准。第 1 期的内部备注和审核记录里的期数（"第 5 期展开""第 13 期""CRISPR 期"）是 v1 编号，**以本表为准**。
- 状态：`未还` / `已还（第 N 期）` / `部分已还`。还账的那一期要在脚本里明确接回去（"第 1 期我们说过……"），并尽量用原镜头。
- 一笔账超过 20 期没还，要在最近一次复盘期里向观众重申"这个还没讲，会在……讲"。
