# 前沿课候选池

前沿课不设固定比例，按**前置解锁**排期：一条候选需要的概念（`needs`，对应 [`concepts.yml`](concepts.yml) 的 id）都已在更早的期数引入，才能排。

**入池标准**

1. 改变了"状态 + 扰动 → 新状态"这个函数的某一部分：状态表示、扰动类型、学习方法、评估方法，至少一项有实质变化。
2. 能回答"它比最笨的办法好多少，谁验证的"。回答不了的，只能作为"有争议"素材出现在别的期里。
3. 出处核实过：进池时必须有 DOI 或预印本编号，并写明核实日期和方式。预印本标 `预印本`，正式发表后更新。

**每条的格式**

```
### 标题（一句话说它改变了什么）
- 出处：作者. 标题. 期刊 年;卷(期):页. doi
- 核实：日期，方式（PubMed 摘要 / 全文 / 官方页面）
- 类型：已发表 / 预印本
- 改变了函数的哪一部分：状态 / 扰动 / 学习方法 / 评估
- 最笨的办法：比了什么基线，结果如何，谁验证的
- needs：[概念 id, ...]
- 状态：候选 / 已解锁 / 已排期（第 N 期）/ 已讲（第 N 期）/ 放弃（原因）
- 易变：是 / 否（"是"的条目每半年重查一次）
```

每周的文献雷达只往"待筛选"里加条目，不改上面的规则，也不直接排期。
