# Agents 布局

每期谁检查什么、拿到什么、交出什么。提示词在 `.claude/agents/*.md`（在本仓库里开的任何会话都能按名字调用），每个文件正文第一行是版本号；每期的 `reviews/` 记录要写明用的是哪一版。

## 原则

1. **能写成测试的不交给 agent。** 数字、溢出、读音比对、音量、前置闭合都是脚本。agent 只做需要判断的事。
2. **审核者只拿到他那个角色本来能拿到的东西。** 新生看不到大纲和事实清单；默片观众看不到脚本。
3. **写的人不核实自己。** 事实核查先只看脚本，自己列清单、自己查，做完才和主笔的 `facts.md` 对比。
4. **提示词入库，带版本号。** 改提示词要改版本号；同一期的修订稿重审时用同一版，结果才能比较。
5. **模拟新生不等于真新生。** 模型装不出"不知道"，复述只能当弱证据。最有用的信号是它在**揭晓前猜了什么**（第 1 期猜 B ≈ 2，说明悬念成立）。第 1 圈之内要找真新生看一次（见 `docs/workflow.md`）。

## 布局

| 阶段 | 谁 | 拿到什么 | 交出什么 |
|---|---|---|---|
| 选题 | 脚本 `tools/check_prereq.py --plan N --uses …` | `concepts.yml`、各期 `meta.yml` | 本期打算用的概念里哪些还没讲 |
| 写稿 | 主笔（主会话） | 全部 | `script.md`、`facts.md`、`storyboard.md`、`meta.yml` |
| 脚本审核 | `freshman-follower` 追更的新生 | 本期脚本 + 之前各期脚本全文 | 复述、揭晓前的猜测、卡点、剩下的"为什么" |
| | `freshman-dropin` 路过的新生 | 只有本期解说词（`tools/strip_cues.py` 去掉画面提示） | 同上，另加"没看过前面、只听不看，哪里跟不上" |
| | `feynman-reviewer` 费曼审核 | 脚本、九条、大纲、概念账、欠账表、之前各期脚本 | 按严重度排序的问题清单；本期新许的愿、新概念 |
| | `fact-checker` 事实核查（第一遍） | **只有脚本**；做完自己的清单后才看 `facts.md` | 逐条结论和出处；主笔漏列的说法 |
| | 脚本 `check_numbers`（第 2–3 期写） | 脚本、toycell | 每个数字与模拟是否一致 |
| 👤 关卡 1 | 你 | 脚本 + 分镜表 + 审核摘要 | 通过或意见 |
| 配音 | 主会话 + whisper 比对 | 音频、原稿 | 逐段转写比对，只把可疑处交给人判断 |
| 画面 | 主会话 | 分镜表、`docs/directing.md` | `video/`、关键帧联系表 |

| | `fact-checker`（第二遍） | 联系表 | 画面本身有没有说错科学 |
| | 检查脚本（`docs/directing.md` 第 8 节） | 渲染出的帧 | 溢出、静止帧、数字 |
| 英文 | 改写（主会话） | 中文定稿 | `script.en.md`、`i18n/en.json` |
| | `en-freshman-native`、`en-freshman-nonnative` | 只有英文脚本 | 复述、猜测、卡点、难懂的说法 |

| 👤 关卡 2 | 你 | 中英成片 | 通过或意见 |
| 👤 关卡 3 | 你 | `publish.md` | 在聊天里明确说"发布" |
| 发布后 | 定时任务"复盘检查"（每周一） | 发布满 14 天、还没有 `retro.md` 的期 | 提醒；数据到手后写 `retro.md` 和规则修改建议 |
| 每周 | 定时任务"文献雷达"（每周六） | PubMed、bioRxiv | 追加到 `docs/frontier-pool.md` 的"待筛选"，不改别处 |

两个定时任务只在本机 Claude 应用开着时运行，都不提交、不推送、不发布。

## 怎么调用

脚本审核的四个 agent 并行起，互相看不到对方的结果：

```
freshman-follower   本期 script.md；之前各期 script.md 的路径
freshman-dropin     tools/strip_cues.py 生成的只听版（放在仓库外的临时目录）
feynman-reviewer    本期 script.md
fact-checker        本期 script.md（第一遍）
```

汇总写进本期 `reviews/feynman.md`（讲法）和 `reviews/factcheck.md`（事实），开头写明各 agent 的版本号。修订后只重跑受影响的审核：改了讲法重跑两个新生，改了事实重跑事实核查。

## 模型

新生和默片观众用便宜的模型（提示词里 `model: sonnet`）：他们的价值在于"不知道"，不在于聪明。主笔、费曼审核、事实核查、忠实度审核用主会话的模型（`model: inherit`）。
