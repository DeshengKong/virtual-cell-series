# 导演规范

每一期的画面和节奏照这份文件做。讲法规则（八条）在 [`episodes/README.md`](../episodes/README.md)，审核规范在 [`feynman-review.md`](feynman-review.md)，流程在 [`workflow.md`](workflow.md)。

总原则：**把注意力花在让观众理解上。** 画面上任何一个元素、任何一个动作，如果去掉后观众理解得一样好，就去掉。

## 1. 每期的骨架

| 段落 | 做什么 | 约束 |
|---|---|---|
| 冷开场 | 揭晓上期思考题，带出这期的问题 | ≤ 25 秒；先给结果，再问为什么 |
| 定位 | 四问题地图亮一格："今天讲机器的这一块" | ≤ 5 秒；每期都有 |
| 现象 | 在玩具细胞（或真实数据）上做一件事，让观众看见 | 先看见，后解释 |
| 先猜 | 问观众会怎样，停 2 秒 | 每期至少一次；停顿写进 `make_cues.py` 的 `PAUSES` |
| 揭晓与原因 | 结果，然后是为什么 | 原因要能从画面上已有的东西推出来 |
| 起名字 | 现在才给术语 | 每期新术语 ≤ 3 个；先有东西，后有名字 |
| 类比 | 一个生活类比，并说清在哪里失效 | 没有失效处的类比不用 |
| 回到机器 | 这一期给"状态 + 扰动 → 新状态"添了什么 | 用第 1 期的机器原镜头 |
| 收尾 | 一句话总结；真实细胞里对应什么、哪里不一样（20–30 秒）；思考题 | 思考题的答案必须能由 toycell 算出来 |

时长不卡死，讲明白优先。骨架是顺序，不是模板：复盘期、前沿课可以省略或合并段落，但"定位、先猜、收尾"不能省。

## 2. 结构：章 → 节拍 → 句

- 一章一张图。章内不切换画面，只在同一张图上逐个节拍加东西、换焦点。
- 一个节拍 4–6 秒，对应一句旁白，画面只发生一件事。
- 标题逐节拍重写：标题说的是此刻画面上正在发生的事，不是这一章的名字。
- 同一个例子贯穿全片（玩具细胞）。换例子要有理由。
- 概念先于术语：画面上先出现那个东西，术语标签晚于旁白里起名字的那一句。

## 3. 画面规则

1. **一刻一个焦点。** 金色只给当前正在讲的那一个东西；同一时刻只有一类东西在动。
2. **画面字是关键词，不是旁白。** 有字幕了。画面标签中文 ≤ 12 字，英文 ≤ 7 个词。
3. **同一个意思永远用同一个动作**（见第 5 节动作词表）。新动作先登记再使用。
4. **回忆旧内容时用原镜头。** 把那一期的画面代码原样调出来，观众一眼认得；不重画一个"差不多的"。
5. **不许长时间静止。** 任何一段画面静止不超过 6 秒。英文版比中文长约 30%（第 1 期 7.5 分钟对 5.8 分钟），同一画面被拉长，英文版要单独检查。
6. **数字都有出处。** 画面上的模型数值只能从 `data.js`（由 `make_data.py` 调 toycell 生成）读，不手写。需要和旁白对拍时只调播放速度，不改数据。
7. **每个数字、每个说法带来源标签**（第 6 节）。
8. **封面写反直觉的结果，不写题目。** 例：第 1 期"没碰 A，A 却翻倍了"。封面上的数字同样来自模拟。
9. **不用论文原图。** 所有画面由代码重画；重画别人的结果要在 `facts.md` 写明出处。

## 4. 色彩语义（全系列固定）

底色 `#0E161D`，卡片 `#16212a`，描边 `#2c3a45`。

| 颜色 | 值 | 只表示 |
|---|---|---|
| 钢蓝 | `#8FB3C8` | 柱子、正常状态 |
| 亮蓝箭头 | `#4fa3ef` | 推动（激活） |
| 朱橙丁字头 | `#e4572e` | 压住（抑制） |
| 紫 | `#a78bfa` | 人为干预（扰动、药物） |
| 深灰 | `#4a5863` | 被关掉 |
| 金 | `#F0B429` | 临时焦点："看这里" |
| 绿 | — | 只用于"正确 ✓"，一期最多一次 |

一种颜色不许有两个意思。需要新的语义色时，先改这张表。

> 第 1 期 `script.md` 的画面提示里把推动箭头写成"绿色箭头"，成片用的是亮蓝。以成片和本表为准。

## 5. 动作词表

| 动作 | 只表示 |
|---|---|
| 柱子升降 | 量变（数值来自模拟） |
| 箭头上跑的光点 | 影响在传递 |
| 变成深灰 | 被关掉 |
| 紫色的东西进场 | 人为干预 |
| 飞入 | "这个就是那个"（如三根柱子飞进机器的"状态"输入口） |
| 问号 | 请你猜 |
| 金色圆环闪一下 | 看这里 |
| 描边画出 | 圈定范围 |
| 列表逐条淡入 | 一条一条读 |
| 下落 / 滑动 / 卡住 | 物理上的原因 |
| 数字滚动 | 规模（如 3 → 将近 2 万） |

缓动只用 ease-out 和 ease-in-out，不用回弹。

**提示音（试行）**：第 2–3 期试一次代码合成的提示音，只给两类事件：柱子变化、揭晓。不加配乐。音效代码入库，音频文件不入库。两期后对比留存，在复盘里决定留不留。

## 6. 来源标签

全系列只有四种，画面上用小字常驻或随数字出现：

| 标签 | 用在 |
|---|---|
| `设定的` / set by us | 玩具细胞的规则和参数 |
| `算出来的` / calculated | 由规则算出的结果 |
| `测出来的` / measured | 真实实验数据（`facts.md` 里要有出处） |
| `还不知道` / not yet known | 未知或有争议（有争议的要说是谁和谁在争） |

诚实标注：

- 示意图常驻"示意图 / Schematic"。不按比例的写"不按比例"。
- 玩具细胞出现时常驻"玩具细胞（我们设计的）"。
- 每处简化都交代真实情况，一句话即可（第 1 期："真实细胞不会降得这么干脆"）。

## 7. 分镜表

脚本通过审核后、写代码前，出一张表，放在该期 `storyboard.md`，和脚本一起给用户审（关卡 1）：

| 节拍 | 对应旁白句 | 画面上有什么 | 什么在动 | 数字从哪来 |
|---|---|---|---|---|
| 3.4 | "先猜一下：我们没有碰 A，A 会怎么样？" | 三根柱子，B 已变灰 | A 上方出现问号，停 2 秒 | — |
| 3.5 | "B 没了，C 失去了推动……" | 同上 | B、C、A 的柱子依次变化 | `simulate()`，敲除 B，t = 0–20 |

"什么在动"一格里出现两类东西，就拆成两个节拍。"数字从哪来"一格里只许写 toycell 调用、`facts.md` 条目编号，或"—"。

## 8. 画面检查

| 检查 | 方式 | 状态 |
|---|---|---|
| 文字溢出、压字（中英两种语言、所有节拍） | 脚本：在浏览器里量每个文字框是否超出容器、是否互相重叠 | 第 2–3 期写 |
| 静止过久、变化过密 | 脚本：逐秒比较帧差，报出静止超过 6 秒的区间 | 第 2–3 期写 |
| 画面数字与模拟一致 | 脚本 `check_numbers`：脚本和 `i18n/*.json` 里出现的数字与 toycell 输出逐个比对 | 第 2–3 期写；已发布数字现由 `toycell/tests/test_published_numbers.py` 锁住 |
| 默片测试 | agent `silent-viewer`：只给关键帧联系表，不给脚本，问"这期在讲什么，哪里看不懂" | 第 2 期起 |
| 画面有没有说错 | agent `fact-checker` 第二遍：拿联系表查画面本身的科学错误 | 第 2 期起 |
| 避坑清单 | 主会话：每次渲染关键帧后逐条自查（下节） | 一直在做 |

## 9. 避坑清单

每次渲染关键帧联系表后逐条过一遍。前 8 条来自此前的制作经验，9–12 条是第 1 期制作中加的。

1. **大字压在数据上。** 结论文字出现时，背景元素降到 ≤ 10% 亮度。
2. **小图挤在一起。** 并排的小图之间至少留 36 px。
3. **标签被线穿过。** 标签放在线外，或加底衬。
4. **一种颜色两个意思。** 对照第 4 节的表。
5. **标题里的数字和画面对不上。** 在关键帧上逐个核对。
6. **注释区压到字幕。** 注释区底边 ≤ 字幕顶边 − 60 px。
7. **焦点环盖住文字；标签写在形状里面；进度条不从 0 开始。**
8. **清单本身没过。** 每次渲染关键帧后都要过，不是只在最后过一次。
9. **英文更长。** 英文标签比中文宽，要单独出联系表；西文专用的版式改动用 `CJK()` 判断，保证中文画面逐像素不变。
10. **示意图说错科学。** 第 1 期初版里药物分子穿过了细胞核。示意图里每个东西的位置和走向都要问一句"真的是这样吗"。
11. **重复出现的元素。** 同一个标签、同一个图例在一帧里出现两次。
12. **念出来的和画出来的不同步。** 旁白说"A 升高"时 A 的柱子必须正在升，早半秒晚半秒都不行；节拍阈值对到句子起点上。
