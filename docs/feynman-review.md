# 费曼审核规范

每期脚本定稿前必须通过两道独立审核。审核者只拿到脚本和前置材料，不拿到作者的解释，避免被作者的思路带偏。

## 审核一：新生复述测试（模拟观众）

审核者扮演一名刚入学的大一新生：高中生物和数学水平，没有看过本系列的其他内容（第 N 期时，只给他第 1 至 N−1 期的"一句话总结"）。

要求他：
1. **复述**：不看脚本，用自己的话把这期讲的核心讲给一个同学听。复述错了或漏掉核心，这期就不通过。
2. **卡点**：逐段标出哪一句听不懂、哪一句要倒回去重听、哪个词不认识。
3. **没回答的"为什么"**：听完后心里还剩哪些"为什么"。
4. **注意力**：哪一段最想快进，哪一段最有意思。

## 审核二：费曼标准审核

依据《费曼物理学讲义》的讲法，逐条检查：

1. **名字不等于理解。** 每个术语出现前，观众是否已经知道它指的是什么、能做什么？先有东西，后有名字。
2. **每个"是什么"都要有"为什么"或"怎么知道的"。** 不允许无理由的断言；确实只能告知的事实（如测量数据），要说明是测出来的、怎么测的。
3. **从看得见、摸得着的东西出发。** 具体例子在前，抽象概括在后。
4. **类比必须说清在哪里失效。** 只给类比不给边界，等于埋下误解。
5. **简化可以，说错不行。** 简化后的说法必须是"低分辨率下仍然正确"，而不是"方便理解但其实是错的"。
6. **诚实区分已知与未知。** 已证实、有争议、没人知道，三者不能混。
7. **前置闭合。** 本期用到的每个概念，要么是高中常识，要么在之前的期数讲过，要么本期当场讲清。不够就加铺垫，宁可多一期。
8. **一期一个想法。** 新术语不超过 3 个；数一数，超了就拆。
9. **让观众自己想一步。** 至少有一处停下来让观众先猜，再揭晓。

输出：按严重程度排序的问题清单，每条给出原句、问题、改写建议。

## 通过标准

- 新生复述抓住了核心，且没有误解；
- 费曼审核没有"说错"（第 5 条）或"前置不闭合"（第 7 条）类问题；
- 其余问题作者逐条处理或写明不改的理由，记录在该期 `reviews/feynman.md`。
