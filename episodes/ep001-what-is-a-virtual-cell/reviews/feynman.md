# 用户审阅 v0.3（2026-11-08）

结论：有条件通过脚本内容审阅，暂不通过制作前科学终审。6 项检查表及 v0.4 处理：

| 检查项 | v0.4 处理 |
|---|---|
| 统一基因 / RNA / 蛋白质口径 | 柱子明确为"三种调控蛋白的数量"；生产与分解打平；第四节说明测序读的是 RNA（图纸复印件）而非蛋白质 |
| 预测能力去绝对化 | 开场改为"能在特定实验预测部分变化，远做不到任意细胞任意药物"（Ahlmann-Eltze 2025 核实） |
| 核验 toycell 方程与敲除结果 | 方程、参数、初值、敲除实现写入内部备注；审阅者独立构造的模型与 toycell 方程不同但结果一致（B 的饱和形式不同：审阅者 4A/(3+A)，toycell 2A²/(1+A²)，均给出 A=2→B=1.6）；新增制作验收：动画由 simulate() 驱动 |
| 天气类比 | 删"没法拿天气做实验"；改为"天气预报主要预测自然变化"；第三处改为"有成熟物理方程，细节仍需近似" |
| 单细胞测序例外 | 加"不打碎细胞的新方法有，但远不能像拍视频一样连续记录"（Live-seq 2022 核实） |
| 时长 | 压缩开场与第四节；正文约 1576 字，估约 4 分 50 秒 + 停顿；以实际配音时长为准 |

新增核心领悟句（审阅者指出的本集最有科学价值之处）："只知道细胞现在的样子还不够，还得知道里面的规则。"
