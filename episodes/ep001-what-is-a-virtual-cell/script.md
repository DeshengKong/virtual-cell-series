# 第 1 期 · 什么是虚拟细胞

> 状态：v0.3（2026-11-08），v0.2 新生复述测试后小修，待用户审
> 这期只回答一个问题：**虚拟细胞到底想预测什么？**
> 目标时长约 4 分钟（Charon 中文约 5.4 字/秒）
> 新术语只有三个：虚拟细胞、状态、扰动
> 〔方括号〕是画面提示，不念。

---

## 一、开场问题（约 30 秒）

〔黑底，一个细胞轮廓缓缓浮现。旁边出现几个药瓶。〕

假如你生病了，医生手里有好几种药。

医生会根据大量病人的试验结果来挑，有时还参考你的基因检测。但落到具体某个人身上，很多时候还是用了才知道。

〔药瓶一个个靠近细胞，细胞里几根小柱子各自升高、降低。〕

那么，能不能先在电脑里，让一个"虚拟的细胞"对每一种药做出反应，提前看看会发生什么？

这就是"虚拟细胞"这个领域想做到的事。

先说清楚：今天还做不到可靠地预测；而且它预测的只是细胞的反应，药在整个身体里的效果是另一回事。为什么这么难，正是这个系列要讲的。

## 二、它到底在预测什么（约 30 秒）

〔画面中央出现一台机器：左边两个入口，右边一个出口。〕

把"虚拟细胞"这个词拆开，它的本质只有一句话：

〔逐项点亮〕

输入：细胞现在是什么状态，再加上，你对它做了什么。
输出：它会变成什么。

"你对它做了什么"，可以是加一种药，可以是关掉一个基因（实验室里有专门的工具做到这一点，后面会讲），也可以是给它一个外界的信号。科学家把这些统称为"扰动"。

那"状态"是什么？光说很抽象，我们直接造一个细胞来看。

## 三、玩具细胞：亲手跑一次预测（约 90 秒）

〔深色背景。三个圆点依次出现，标 A、B、C。每个圆点下方一根柱子。〕

这是一个最简单的细胞，它只有三个基因：A、B、C。

你在高中学过，基因就像一份图纸，细胞照着它生产一种分子。图纸本身不会变多，会变的是照着图纸生产出来的东西有多少。所以下面这三根柱子，表示的是每个基因此刻的"产量"。

〔A 到 B 出现绿色箭头〕A 的产物，会推动 B 的生产；
〔B 到 C 出现绿色箭头〕B 的产物，会推动 C 的生产；
〔C 到 A 出现红色"⊣"〕而 C 的产物，反过来会压住 A 的生产。这个丁字头的符号，就表示"压住"。

〔三根柱子上下晃动几下，最后停在同一高度，标"1"。〕

不去打扰它，三根柱子最后会停在一个固定的高度，不再变化。我们把这个高度记作 1。

〔三根柱子旁边出现一个括号，标"状态"。〕

这三根柱子的高度，就是这个细胞此刻的"状态"。

现在，我们做一个扰动：把基因 B 关掉，也就是让细胞不再照着 B 的图纸生产。

〔B 的柱子开始下降，B 圆点变灰。〕

你先猜一下：我们没有碰 A，A 会怎么样？

〔停顿 2 秒，A 上方出现"？"〕

〔动画按先后顺序渐变：B 先降，C 随后降，A 最后升。〕

B 没了，C 失去推动力，慢慢降到 0。真实细胞不会降得这么干脆，这里是玩具的简化。

而 C 原本一直压着 A。原来 A 被压着，只开了一半的马力；压力没了，A 开足马力，产量涨到原来的 2 倍，然后停在那里。

〔A 柱子停在 2，红色符号消失。〕

注意这个结果：我们根本没有碰 A，A 却变了。

这就是预测细胞难的地方：基因之间连成一张网，你动一个地方，影响会沿着网传开好几步。只看一步的直觉，很容易漏掉。

〔回到机器画面：三根原始柱子飞进左边第一个入口，"关掉 B"飞进第二个入口，新的柱子从右边出口出来。〕

回到开头那台机器：三根柱子原来的高度，就是"细胞现在的状态"；关掉 B，就是"你做了什么"；等它重新安定下来，柱子停在哪里，就是机器给出的"新状态"。

刚才这一次，我们亲手跑了一遍虚拟细胞。它能算出来，是因为三个基因之间"推多少、压多少"的规则是我们事先定好的。"一半"和"2 倍"都是从这些规则算出来的，不是随口说的；后面讲调控网络的那几期，会带你亲手算一遍。

## 四、它像天气预报，但有三处不像（约 60 秒）

〔切到天气画面：今天的云图 → 明天的云图。〕

你可能觉得，这有点像天气预报：输入今天的温度、湿度、风向，算出明天会不会下雨。

确实像，但有三处不一样，正好是这个领域最难的地方。

〔画面分成三栏，依次点亮。〕

第一，天气预报回答的是"不管它，它会怎样"；虚拟细胞要回答的是"如果我动它一下，它会怎样"。我们没法拿天气做实验，却可以拿细胞做实验。

第二，细胞很难被"从头看到尾"。用显微镜，我们可以盯着一个活细胞看好几天，但一次只能看清少数几种分子。想一口气读出它成千上万个基因的产量，今天最常用的方法要先把细胞打碎。测完这一次，这个细胞就没了。所以我们很少能拿到同一个细胞完整的"之前"和"之后"。

那怎么办？办法和你高中做的对照实验一样：拿两群差不多的细胞，一群不动，一群扰动，比较两群的差别。但"差不多"不等于"一模一样"，这又带来新的难题，我们后面会专门讲。

第三，也是最根本的一点：大气遵守的物理规律，科学家早就写成了数学式子，天气预报难在算得够不够快、量得够不够全。而细胞里的规律，大部分我们还不知道。玩具细胞里的三条关系是我们自己定的；真实的人类细胞有将近两万个能做出蛋白质的基因，它们之间谁推动谁、谁压住谁，绝大部分还没弄清楚。

〔数字"3"放大成"近 20,000"，再变成一张大部分连线是虚线和问号的网。〕

## 五、两条路（约 30 秒）

〔中央机器再次出现，下方分出两条路。〕

规律不知道，这台机器怎么造？大致有两种思路。

一种，像玩具细胞那样：先把规律一条条弄清楚，写成数学式子，让电脑去算。

〔左边一条路上是写满式子的黑板；右边一条路上，成千上万对"不动 / 扰动"的细胞群像卡片一样流过。〕

另一种：先不写规律，而是收集大量刚才说的那种对照数据，成千上万次"一群不动、一群扰动"，让人工智能从这些差别里自己去找规律。

实际的研究里，这两种思路经常混在一起用。今天，哪一种都还没有走到终点。

## 六、总结和思考题（约 25 秒）

〔四个格子围绕机器亮起：状态、扰动、机器怎么造、怎么检验。不念出来。〕

接下来的每一期，都会回答这台机器的一个部件。

〔画面收回到那句话。〕

这一期只记住一句话：
**虚拟细胞，就是输入细胞的状态和你做的事，预测它会变成什么。**

〔玩具细胞重新出现，这次 C 变灰。〕

留一道思考题：如果关掉的不是 B，而是 C，A 和 B 会怎么变？B 会不会也正好涨到 2？
下一期开头揭晓答案。

## 内部备注（不念）

- 思考题答案（toycell）：敲除 C → A = 2.0，B = 1.6，C = 0。B 升高但到不了 2，因为"推动"会饱和：A 再多，B 的生产也有上限（第 5 期展开）。
- 敲除 B 的动态：C 先逐渐下降，A 随后单调上升到 2，无超调；动画按此先后顺序。
- "A 只开一半马力"：模型中 C=1 时压制项 = 1/(1+1²) = 0.5，A 的最大产量为 2，所以 A = 1；C=0 时 A = 2。
