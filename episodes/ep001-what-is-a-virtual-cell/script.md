# 第 1 期 · 什么是虚拟细胞

> 状态：v0.4（2026-11-08），按用户审阅意见（v0.3 审阅 6 项检查表）修订
> 这期只回答一个问题：**虚拟细胞到底想预测什么？**
> 核心领悟：**只知道细胞现在的样子，还不足以预测你改变一个基因后它会怎样——还得知道里面的规则。**
> 目标时长约 4.5 分钟（Charon 中文约 5.4 字/秒）
> 新术语只有三个：虚拟细胞、状态、扰动
> 〔方括号〕是画面提示，不念。

---

## 一、开场问题（约 30 秒）

〔黑底，一个细胞轮廓缓缓浮现。旁边出现几个药瓶。〕

假如你生病了，医生手里有好几种药。

医生会参考临床试验，有时还看基因检测，但对具体某个人，很多时候还是用了才知道。

〔药瓶一个个靠近细胞，细胞里几根小柱子各自升高、降低。〕

能不能先在电脑里，让一个"虚拟的细胞"对每种药做出反应，提前看看会发生什么？这就是"虚拟细胞"想做到的事。

今天，它已经能在一些特定实验里预测出部分变化，但远远做不到对任意细胞、任意药物都给出可靠答案；药进了人体有没有疗效，更是另一回事。

## 二、它到底在预测什么（约 30 秒）

〔画面中央出现一台机器：左边两个入口，右边一个出口。〕

虚拟细胞的本质只有一句话：

〔逐项点亮〕

输入：细胞现在是什么状态，再加上，你对它做了什么。
输出：它会变成什么。

"你对它做了什么"，可以是加一种药，可以是关掉一个基因（实验室里有专门的工具做到这一点，后面会讲），也可以是给它一个外界的信号。科学家把这些统称为"扰动"。

那"状态"是什么？光说很抽象，我们直接造一个细胞来看。

## 三、玩具细胞：亲手跑一次预测（约 95 秒）

〔深色背景。三个圆点依次出现，标 A、B、C。每个圆点下方一根柱子。〕

这是我们自己设计的一个玩具细胞，它只有三个基因：A、B、C。

你在高中学过，基因就像一份图纸。在这个玩具里，每个基因照着自己的图纸，生产一种能调控别的基因的蛋白质。下面这三根柱子，就表示这三种蛋白质各有多少。

〔A 到 B 出现绿色箭头〕蛋白 A，会推动 B 的生产；
〔B 到 C 出现绿色箭头〕蛋白 B，会推动 C 的生产；
〔C 到 A 出现红色"⊣"〕而蛋白 C，反过来会压住 A 的生产。这个丁字头的符号，就表示"压住"。

〔三根柱子上下晃动几下，最后停在同一高度，标"1"。〕

细胞一边生产这些蛋白质，一边也在不断分解它们。不去打扰它，生产和分解会打平，三根柱子最后停在一个固定的高度。我们把这个高度记作 1。

〔三根柱子旁边出现一个括号，标"状态"。〕

这三根柱子的高度，就是这个细胞此刻的"状态"。

现在，我们做一个扰动：把基因 B 关掉，细胞不再生产蛋白 B，已有的蛋白 B 会慢慢被分解掉。

〔B 的柱子开始下降，B 圆点变灰。〕

你先猜一下：我们没有碰 A，A 会怎么样？

〔停顿 2 秒，A 上方出现"？"〕

〔动画由 toycell 模拟数据驱动，按先后顺序渐变：B 先降，C 随后降，A 最后升。〕

B 没了，C 失去推动力，慢慢降到 0。真实细胞不会降得这么干脆，这里是玩具的简化。

而 C 原本一直压着 A。原来 A 被压着，只开了一半的马力；压力没了，A 开足马力，涨到原来的 2 倍，然后停在那里。

〔A 柱子停在 2，红色符号消失。〕

注意这个结果：我们根本没有碰 A，A 却变了。

再想一想：关掉 B 之前，三根柱子都是 1，光看这三个数字，你能猜到 A 会翻倍吗？猜不到。真正决定结果的，是柱子之间"谁推谁、谁压谁"的规则。所以，只知道细胞现在的样子还不够，还得知道里面的规则。

〔回到机器画面：三根原始柱子飞进左边第一个入口，"关掉 B"飞进第二个入口，新的柱子从右边出口出来。机器内部亮出三条箭头。〕

回到开头那台机器：三根柱子原来的高度，是"细胞现在的状态"；关掉 B，是"你做了什么"；等它重新安定下来，柱子停在哪里，就是机器给出的"新状态"。而机器里面装的，就是那几条规则。

"一半"和"2 倍"都是从定好的规则里算出来的，不是随口说的，后面几期会带你亲手算。

## 四、它像天气预报，但有三处不像（约 55 秒）

〔切到天气画面：今天的云图 → 明天的云图。〕

这有点像天气预报：输入今天的天气，算出明天的天气。但有三处不一样，正好是这个领域最难的地方。

〔画面分成三栏，依次点亮。〕

第一，天气预报主要预测大气会怎么自然变化；虚拟细胞还要回答：如果我们主动动它一下，细胞会怎样。

第二，细胞很难被"从头看到尾"。想一口气读出成千上万个基因的活动，最常用的单细胞测序要先把细胞打碎，测完细胞就没了；不打碎细胞的新方法有，但还远不能像拍视频一样连续记录。而且它读到的主要是 RNA，也就是图纸的复印件，不是柱子里的蛋白质本身。

那怎么办？办法和你高中做的对照实验一样：拿两群差不多的细胞，一群不动，一群扰动，比较两群的差别。但"差不多"不等于"一模一样"，这又带来新的难题，我们后面会专门讲。

第三，最根本：天气预报有成熟的物理方程做基础，虽然细节还要近似；细胞里许多规则本身还没搞清楚。玩具里的三条规则是我们定的；真实人类细胞有将近两万个能做出蛋白质的基因，谁推谁、谁压谁，大部分还不知道。

〔数字"3"放大成"近 20,000"，再变成一张大部分连线是虚线和问号的网。〕

## 五、两条路（约 35 秒）

〔中央机器再次出现，下方分出两条路。〕

规则不知道，这台机器怎么造？大致有两种思路。

一种，像玩具细胞那样：先把规则一条条弄清楚，写成数学式子，让电脑去算。

〔左边一条路上是写满式子的黑板；右边一条路上，成千上万对"不动 / 扰动"的细胞群像卡片一样流过。〕

另一种：先不写规则，而是收集大量刚才说的那种对照数据，成千上万次"一群不动、一群扰动"，让人工智能从这些差别里自己去找规则。

〔画面上方出现一个天平：一边"模型的预测"，一边"实验结果"。〕

不管走哪条路，造出来的机器都要拿真实实验去检验。实际研究里，两条路也常混着用。

## 六、总结和思考题（约 25 秒）

〔四个格子围绕机器亮起：状态、扰动、机器怎么造、怎么检验。不念出来。〕

接下来的每一期，都会回答这台机器的一个部件。

〔画面收回到那句话。〕

这一期只记住一句话：
**虚拟细胞，就是输入细胞的状态和你做的事，预测它会变成什么。**

〔玩具细胞重新出现，这次 C 变灰。〕

留一道思考题：如果关掉的不是 B，而是 C，A 和 B 会怎么变？B 会不会也正好涨到 2？
下一期开头揭晓答案。

## 内部备注（不念）

### 玩具细胞模型（toycell v0.1，`toycell/toycell/model.py`）

每个变量是对应调控蛋白的归一化数量；生产项为 Hill 函数（k = 1，n = 2，最大生产速率 2），降解速率 1：

```
dA/dt = 2 · 1/(1 + C²)   − A      # C 压住 A
dB/dt = 2 · A²/(1 + A²)  − B      # A 推动 B
dC/dt = 2 · B²/(1 + B²)  − C      # B 推动 C
```

敲除某基因 = 其生产项置 0，已有蛋白按降解速率衰减。积分：RK4，dt = 0.01，初值 (0.1, 0.1, 0.1)，取 t = 50 的值。

| 场景 | A | B | C |
|---|---|---|---|
| 不扰动 | 1 | 1 | 1 |
| 敲除 B | 2 | 0 | 0 |
| 敲除 C | 2 | 1.6 | 0 |

- 思考题答案：敲除 C → A = 2，B = 2·4/5 = 1.6。B 到不了 2，因为"推动"会饱和（第 5 期展开）。
- "只开一半马力"：C = 1 时压制项 = 1/(1+1²) = 0.5，A = 2 × 0.5 = 1；C = 0 时 A = 2。
- 敲除 B 的动态：B 先降，C 随后降，A 随后单调升到 2，无超调。
- **制作验收**：动画中所有柱子高度必须由 `toycell.simulate()` 的输出驱动，不允许按预设答案手绘关键帧。
