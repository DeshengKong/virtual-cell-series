# 每期文件夹规范

命名：`epNNN-英文短名/`，例如 `ep001-what-is-a-virtual-cell/`。核心课和前沿课共用一个编号序列，在 `meta.yml` 里区分。

```
epNNN-name/
├── meta.yml          # 标题、类型（core / frontier / revision）、地图位置（①–④）、前置期数、发布日期、视频链接
├── script.md         # 定稿解说词（含画面提示）
├── facts.md          # 片中每一个事实性说法 + 出处（DOI），逐条核实后才能定稿
├── video/            # 本期动画渲染代码（一套代码出两种语言）
├── i18n/
│   ├── zh.json       # 画面上所有文字（中文）
│   └── en.json       # 画面上所有文字（英文），键与 zh.json 一一对应
├── script.en.md      # 英文解说词（由中文定稿翻译并核对术语）
└── notebook.ipynb    # 观众可以自己运行的玩具细胞实验（不是每期都有）
```

## 双语规则

- 中文为主版本，先定稿；英文版从中文定稿翻译，术语以 `docs/glossary.md` 为准。
- 动画代码里不写任何硬编码文字，一律从 `i18n/<lang>.json` 读取。
- 画面事件时间点由各语言配音的逐字时间（faster-whisper）分别生成：`cues.zh.json`、`cues.en.json`。
- 配音：Gemini TTS，每期在 `meta.yml` 里记录模型版本、音色名和风格提示词，保证可复现。音频文件不入库。
- 发布节奏：中文先发 4–6 期定型，之后英文从第 1 期补齐，再两版每周同步。

## 每期讲法（硬规则）

1. 只回答一个问题，结尾用一句话总结。
2. 顺序：具体现象/问题 → 生活类比 → 真实机制 → 类比在哪里失效。
3. 先讲概念，再给名字；模型名只作为例子出现。
4. 开头标出"四问题地图"上的位置；结尾留一道思考题，下期开头揭晓。
5. 前沿内容区分"已证实""有争议""未知"。
6. 不使用论文原图，所有画面由代码重画。
