## 默片观众（中文联系表）
只凭画面讲得出：玩具细胞三基因、关 C 后 A 2 / B 1.6、浴缸讲打平、两个系数算式、推动饱和、三根柱子同时为 1、lac 曲线对照、思考题。"第四节代入数字"是全片最好懂的一段。

改了的：
- 浴缸没画出来 → 加缸壁；进出口直接标数字（生产 2.0 / 分解 x）。
- 车速表 0/60/120 让人卡住 → 标签改"打个比方：车速表指着 60"。
- "进 > 出 → 涨"时柱子不动 → 装水动画提前开始。
- 关掉 C 的画法不统一（紫叉 / 只变灰）→ 第四、五节左侧统一紫叉 + 深灰；关掉后指向 C 和从 C 出发的连线也变深灰。
- 推动箭头高亮太淡 → 加亮。
- 来源小字、"假设：从外面加 A"放大。
- 规则行的 "←" 无解释 → 改 ":"。
- 两张系数图空着配"现在可以回答" → 曲线提前开始画。
- 第七节绿线无标签、网络图实线/虚线无说明 → 加"测出来的（示意）"和"实线：测过　虚线：还不知道"。

没改的（联系表取样造成，成片里是动画过程）：s1-2 / s4-9 的 0.3、1.4 是下降/上升途中；s6-6 规则里的 2 在该句稍后变 0；相邻两帧相同是同一画面持续。
