## 一、上期的答案

〔第 1 期原镜头：玩具细胞，A、B、C 三个点，亮蓝箭头 A→B、B→C，朱橙丁字头 C⊣A；三根柱子都是 1。〕

我们的玩具细胞只有三个基因：A 推动 B，B 推动 C，C 反过来压住 A。每个基因下面一根柱子，表示它的蛋白有多少。上一期留了一道题：如果关掉的不是 B，而是 C，也就是让细胞不再生产蛋白 C，A 和 B 会怎么变？

〔C 变灰。动画由 toycell 模拟驱动：C 降到 0，A 升到 2，B 升到 1.6。〕

答案是：C 降到 0；A 涨到 2，和关掉 B 的时候一样；B 也涨了，但没有到 2，停在了 1.6。

〔B 柱子旁边出现"1.6"，上方一条虚线标"2"，两者之间留一道空隙，金色闪一下。〕

为什么偏偏是 1.6？为什么 A 能到 2，B 却差了一截？这一期，我们只用四则运算，亲手把它算出来。

## 二、今天讲机器的哪一块

〔第 1 期结尾的机器原镜头，四个格子围在四周，逐个点亮，念出来。〕

第 1 期结尾，这台机器周围有四个格子，当时没有念出来。它们是关于虚拟细胞的四个问题：细胞的状态怎么描述；能对细胞做什么；机器怎么造；怎么检验它对不对。

今天讲第三格：机器里面那几条规则，怎么变成数字。

## 三、柱子为什么会停下来

〔回到玩具细胞，只看 A 一根柱子。柱子下方画一个进水口、一个出水口。〕

先从一根柱子说起。第 1 期说过，细胞一边生产蛋白，一边也在分解蛋白。

〔进水口有光点流入，标"生产"；出水口有光点流出，标"分解"。〕

这很像一个浴缸：水龙头往里放水，是生产；排水口往外流，是分解。

分解有多快？想一想：每一个蛋白，在一小段时间里被细胞拆掉的机会大致差不多。那么蛋白多一倍，同样一段时间里被拆掉的也多一倍。也就是说，有多少，分解就有多快。我们给玩具就这样定；真实细胞里，很多蛋白大致如此。

〔出水口旁出现：分解速度 = 现有的量 × 1，旁边小字"设定的"。〕

在我们的玩具里，这个比例定成 1：柱子高 1，此刻每单位时间分解掉 1 份；高 2，就是 2 份。单位时间是玩具里的时间单位，不对应真实细胞里的几分钟、几小时。

〔水龙头开大：柱子升高，出水口的光点跟着变密，直到进出一样快，柱子停住。〕

规则很简单：进来的比出去的多，柱子就涨；少，就降；一样多，就停。水龙头一开，柱子开始升高；柱子越高，流出去越快；一直升到流出去和流进来一样快，柱子就停住了。这就是第 1 期说的"打平"。

〔一个车速表，指针指在 60。〕

注意，刚才说的"每单位时间分解 1 份"，是"此刻"有多快，不是说过一个单位时间就分解光了。就像车速表指着 60，不等于接下来一小时一定开出 60 公里。不过车速是司机踩出来的；这里的分解速度，由柱子自己的高度决定：柱子一降，分解就跟着变慢。

〔屏幕中央：停下来的高度 = 生产速度。〕

在我们的玩具里，分解的比例是 1，所以停下来的高度，在数值上正好等于生产速度。每单位时间生产 1 份，柱子就停在 1；生产 2 份，就停在 2。

〔金色框住"生产速度"。〕

这样一来，想知道柱子停在哪，只要算出它的生产有多快。

浴缸这个比方有一处不像：浴缸里的水是连成一片的，水位平平稳稳；细胞里的蛋白是一个一个的，数量少的时候，会忽多忽少。我们的玩具先把这一点抹平了。

## 四、"压住"的算式

〔回到三个基因。C 到 A 的朱橙丁字头亮起。〕

那生产有多快，由谁决定？由规则决定。先看 A：C 压住 A。

〔A 旁边出现算式，逐项点亮：A 的生产速度 = 2 × 压住系数〕

规则是这样写的：A 的生产速度，等于 2，乘以一个"压住系数"。

2 是 A 开足马力时的生产速度：每单位时间 2 份。压住系数是一个 0 到 1 之间的数，表示此刻还剩几成马力：压得越狠，它越小。

〔下面一行：压住系数 = 1 ÷ (1 + C × C)〕

压住系数是一个分数：分子是 1，分母是 1 加上 C 乘 C。

〔一张小表逐行出现：C = 0 → 1；C = 1 → 1/2。〕

代几个数试试。C 是 0，没人压，分母是 1，系数是 1：开足马力。C 是 1，分母是 2，系数是一半。

〔表的下一行只出现"C = 2 →"和一个"？"。停 2 秒。〕

C 是 2 的时候呢？先自己算一下。

〔"C = 2 → 1/5"出现。〕

分母是 1 加 4，等于 5，系数是五分之一，只剩两成。C 越多，压得越狠。

〔"C = 1 → 1/2"一行亮金色，飞到第 1 期原镜头"一半的马力"字样上。〕

第 1 期说，平时 A 被压着，"只开了一半的马力"。这个一半就是这么来的：平时 C 是 1，系数是一半，A 的生产速度是 2 乘一半，等于 1，所以 A 停在 1。

〔"C = 0 → 1"一行亮金色。A 柱子从 1 升到 2。〕

关掉 C 以后，C 降到 0，系数变成 1，A 的生产速度是 2 乘 1，等于 2，A 停在 2。第 1 期那个"2 倍"，就是 2 比 1。关掉 B 的时候，C 也降到了 0，所以 A 同样停在 2。

## 五、"推动"的算式

〔A 到 B 的亮蓝箭头亮起。B 旁边出现算式：B 的生产速度 = 2 × 推动系数〕

再看 B：A 推动 B。B 的生产速度，等于 2，乘以一个"推动系数"。

〔下面一行：推动系数 = (A × A) ÷ (1 + A × A)〕

推动系数也是一个分数：分子是 A 乘 A，分母是 1 加上 A 乘 A。

〔小表逐行出现：A = 0 → 0；A = 1 → 1/2；A = 2 → 4/5。〕

同样代几个数。A 是 0，分子是 0，系数是 0，没人推，B 一点也不生产。A 是 1，二分之一：A 到 1 的时候，正好推到一半。A 是 2，分子是 4，分母是 5，五分之四，也就是 0.8。

〔"A = 2 → 4/5"一行亮金色。B 柱子停在 1.6，旁边写"2 × 0.8 = 1.6"，小字"算出来的"。〕

关掉 C 以后，A 是 2，B 的生产速度就是 2 乘 0.8，等于 1.6。B 停在 1.6，上期思考题的答案，就是这么算出来的。

〔A 柱子旁出现一个紫色的"+"，小字"假设：从外面加 A"。〕

那如果 A 更多呢？在玩具里，A 最多只到 2；我们假设从外面直接往细胞里加 A 蛋白，只拿算式算一算。你先猜一下：A 要多大，B 才能正好到 2？

〔停顿 2 秒，B 柱子上方"2"的虚线旁出现"？"。〕

〔表格继续往下长：A = 3 → B = 1.8；A = 4 → 约 1.88；A = 10 → 约 1.98。B 的柱子一次次升高，越来越贴近虚线，始终不碰到。〕

A 从 2 加到 3，B 多了 0.2，到 1.8；再加到 4，只多了不到 0.1；加到 10，B 也才 1.98。越来越近，但永远到不了 2。

〔分子"A × A"和分母"1 + A × A"各亮一次。〕

原因就在算式里：分母永远比分子多 1。所以不管 A 有多大，推动系数都比 1 小，A 越大，只是越接近 1。B 的生产速度也就总比 2 少一些。

〔屏幕中央出现"饱和"。〕

越推越不划算：越靠近顶，多推一份换来的越少；在我们的算式里，推得再多也只能贴近，碰不到。科学家把这叫作"饱和"。化学里的饱和溶液，是真的到了顶，再加也溶不进去；这里的饱和，是一点点贴近顶，永远差一点。共同点是：越往后，多加一份，越不起作用。

〔左右并排两个小图：左边压住系数随 C 变化，C = 0 处正好碰到 1；右边推动系数随 A 变化，一直贴着 1 的下方。〕

现在可以回答开头的问题了。压住和推动，上限都是开足马力的 2。区别在够不够得着：压住，只要 C 真的降到 0，系数正好是 1，A 正好到 2；推动，要 A 无穷多才够得着，A 是 2 的时候系数只有 0.8，所以 B 停在 1.6。

〔A × A 那一项闪一下；旁边并排两行小表：只用 A：0.5 → 1/3，2 → 2/3；A 乘 A：0.5 → 0.2，2 → 0.8。〕

你可能会问：为什么是 A 乘 A，不是只用 A？比一比。只用 A 的话，A 是 0.5 的时候，系数是三分之一；A 是 2 的时候，是三分之二；乘两次，变成 0.2 和 0.8。少的时候更少，多的时候更多，推动就更像一个开关。不过它不是真的开关，没有"啪"的一下，而是一段很陡的坡。压住那边的 C 乘 C，也是同一个道理。

这两个算式是我们挑的。挑它们，是因为不少真实基因测出来，就是这种先平、后陡、再平的形状。

## 六、三根柱子同时打平

〔三个基因、三条规则同时显示：A ← 压住系数(C)，B ← 推动系数(A)，C ← 推动系数(B)。〕

C 的规则和 B 一样：B 推动 C，C 的生产速度等于 2 乘推动系数，只不过系数里用的是 B。

〔环形箭头 A → B → C → A 亮一圈。〕

A 推 B，B 推 C，C 又绕回来压 A：三条规则首尾相连，绕成一个环。

现在回头看平时那三个 1。

〔逐条代入 A = B = C = 1，每条右边算出 1，打勾，小字"算出来的"。〕

把 A、B、C 都是 1 代进去：A 的生产速度，2 乘一半，是 1；B 的，2 乘一半，是 1；C 的，也是 1。三根柱子的生产速度都是 1，正好等于它们现在的高度，每根柱子的生产和分解，在这里同时打平。平时三根柱子都停在 1，就是这个原因。

〔小字："开足马力 2、推到一半的量 1，都是我们挑的数（设定的）。"〕

第 1 期我们说，把这个高度"记作 1"。其实是倒过来做的：我们先挑好规则里的数，开足马力是 2，推到一半要的量是 1，让它正好算出 1，这样最好算。

〔回到机器原镜头：左边入口"三根 1"，"关掉 C"飞进第二个入口；机器内部亮出三条算式，其中 C 那一条的"2"变灰成"0"；出口出来 A 2、B 1.6、C 0。〕

关掉 C，等于把 C 那条规则里的"2"改成了 0：不再生产。机器要找的新状态，就是改完规则之后，每根柱子的生产和分解重新同时打平的那组数：C 没了生产，降到 0；C 是 0，A 停在 2；A 是 2，B 停在 1.6。

〔C → A → B 三步依次亮起，每一步旁边写出算式。〕

加药也是一样。比如一种药让 A 开足马力也只有原来的一半，就是把 A 那条规则里的 2 改成了 1。这一期给机器添的就是这件事：扰动改了规则，新状态就是每根柱子重新打平的地方。

〔环上 C 处出现一道"剪断"的缺口。〕

不过要说清楚：这次能顺着一路算下来，是因为 C 变成了 0，环在这里断开了。如果环不断，比如刚才那种药，A 一变，B、C 都会跟着变，又绕回来影响 A，没法顺着一路算到底。也可以把三个式子当成方程组一起解，但它们不是高中那种简单的一次方程，解起来很麻烦。另一个办法是：从某一刻出发，一小步一小步往前推，看柱子最后停在哪。这是下一期的事。那种药到底让 A 降多少，是不是正好一半，第 4 期再算。

## 七、真实细胞里，和总结

〔切到"真实细胞"标签。一个细菌轮廓，里面一个基因接着一盏绿灯。一条先平、后陡、再平的曲线，标"示意"；小字"测出来的：大肠杆菌的 lac 基因"。〕

真实细胞里也是这样吗？有一部分是。科学家在大肠杆菌里，把控制一个基因开工的那一段，接到一个会发绿光的蛋白上：基因开工越快，细胞亮得越快。他们往细胞里加一种能让这个基因开工的小分子，加得越多，这个基因生产得越快，最后几乎不再涨，贴着一个平顶走。这条曲线也是先平、后陡、再平，和我们挑的算式是同一个样子。

〔曲线左端抬起一点，标"漏出一点"。〕

但也有不一样的地方。我们的算式里，没人推时系数正好是 0。所以第 1 期关掉 B 以后，C 没人推了，降得干干脆脆，正好到 0；真实的基因没人推的时候，常常也不是正好 0，还会漏出一点点。第 1 期说"真实细胞不会降得这么干脆"，这是原因之一。

〔小字"还不知道"浮在一张大部分连线是虚线的网上。〕

还有，真实细胞里，算式里的那几个数，开足马力是多少、推到一半要多少、乘几次也就是坡有多陡，不是谁定的，要靠实验去测，而真正细测过的，只是极少数。

〔画面收回到一句话。〕

这一期只记住一句话：
**柱子停在生产和分解打平的地方；推动会饱和，推得再多也到不了顶。**

〔玩具细胞重新出现，三根柱子都在 0。〕

留一道思考题：一个刚"开机"的玩具细胞，三根柱子都是 0。用今天的三个算式算一算：这一刻，哪根柱子在涨，哪根不动？
下一期开头揭晓。

### 模型与数字（toycell v0.1，全部由 `toycell` 复算）

```
A 的生产速度 = 2 × 1/(1 + C×C)       # 压住
B 的生产速度 = 2 × A×A/(1 + A×A)     # 推动
C 的生产速度 = 2 × B×B/(1 + B×B)     # 推动
分解速度 = 现有的量 × 1                # 打平时：高度 = 生产速度
```

| 量 | 值 | 复算 |
|---|---|---|
| 平时 | A 1, B 1, C 1 | `predict([0.1]*3)`；`derivatives([1,1,1])` = 0 |
| 关掉 C | A 2, B 1.6, C 0 | `predict([1,1,1], Perturbation(knockout={'C'}))` |
| 关掉 B | A 2, B 0, C 0 | 已发布数字 |
| 压住系数 | C=0 → 1；C=1 → 0.5；C=2 → 0.2 | 1/(1+C²) |
| 推动系数 | A=0 → 0；0.5 → 0.2；1 → 0.5；2 → 0.8 | A²/(1+A²) |
| 只用 A 的对照 | A=0.5 → 1/3；A=2 → 2/3 | A/(1+A)（只在画面小表里，不进 toycell） |
| B 随 A（假设从外面加 A，只代算式） | A=3 → 1.8；4 → 1.882；10 → 1.980 | 2A²/(1+A²) |
| 思考题 | 全 0 时生产速度 A 2、B 0、C 0：只有 A 在涨 | `derivatives([0,0,0])` = [2, 0, 0] |

- 关掉 C 的动态：C 先降，A 随后升，B 最后升；无超调（B 最大 1.6000，A 最大 2.0000）。
- 思考题延伸（第 3 期用）：从全 0 开机，A 先冲到约 1.58（t ≈ 1.9）再回落，最后三根都停在 1。这是"半路上"和"稳定下来"的区别。
- "推到一半的量是 1"是 k = 1；"乘两次"是 n = 2。本期不出现 k、n 这两个字母。
- 环断开才能一路算：关掉 B 或 C 都把环剪断。关掉 A 也一样（A = 0 → B = 0 → C = 0）。A×0.5 时环不断，第 4 期的数字 0.7161 靠一步一步算（第 3 期讲方法）。也可以"猜一个 A、绕环算一圈、对不上再调"，本期只点"其中一个办法"，不否认别的办法。
- 单位时间：分解比例 1，相当于半衰期约 0.7 个单位时间。不要把单位时间说成"一分钟"（事实核查第一轮 ⚠️ #6）。

### 讲法上的取舍

- 浴缸类比的失效处选"分子一个一个、数量少时忽多忽少"，为第 3 圈 · 随机性埋一笔（M6）。
- "为什么乘两次"给了对照数字和"像开关但不是开关"；真实机理（几个蛋白抱团才推得动）留到第 2 圈 · 调控网络。
- 真实细胞的例子用 Setty 2003 的 lac：只说"往细胞里加一种能让这个基因开工的小分子"（不用"开机信号"，避免和思考题的"开机"撞词），不说"推动它的蛋白"，因为两个输入一个是激活（cAMP-CRP）、一个是解除压住（IPTG-LacI）。曲线是示意，不按论文数据画。不拿它当渗漏幅度的例子（报告质粒缺 O2，关闭偏弱）。
- 追更新生第二轮问："B 贴近 2 碰不到"和"柱子随时间越来越接近停住的高度"是不是一回事？第 3 期要正面回答：随时间的接近也是一点点贴近（玩具里分解按比例，越接近越慢），和本期的"算式上限"是两件事。
- 配音后改词："A 是 0.5 时""A 是 2 时"的"时"和"十"同音（转写成 0.50、20），改成"的时候"。
- 第二节念四个格子约 15 秒，超过骨架"定位 ≤ 5 秒"。第一次念出来是计划内的例外，第 3 期起回到 ≤ 5 秒。
